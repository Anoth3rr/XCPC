# 错题本

## 检查

1. 输入范围、是否多测、模数是否质数、图是否有重边/自环、答案是否需要取模。
2. 把所有全局数组、邻接表、堆、哈希表和计数器按测试用例清空；尤其检查 `static`、对象复用和时间戳数组。
3. 搜索 `INF`、`1<<`、`/`、`%`、`size()`、`assert`、`cerr`、`freopen`，逐处确认没有边界或环境问题。
4. 检查最后一个合法下标、空容器、`n=0/1`、只有一条边、全相等、全负数、模数为 2 等极端输入。
5. 本地编译一遍 `-std=c++17 -O2 -pipe -Wall -Wextra`；提交前去掉调试输出和本地文件重定向。

## 编译与本地调试

调试命令：

```text
g++ -std=c++17 -O2 -pipe -Wall -Wextra -Wshadow -Wconversion main.cpp -o main
g++ -std=c++17 -O0 -g -D_GLIBCXX_DEBUG -fsanitize=address,undefined main.cpp -o main_dbg
```

`-Wconversion` 可能对竞赛中有意的窄化产生大量提示，正式卡常前再决定是否保留；它不是替代逻辑检查的证明工具。递归 DFS、点分治、线段树和支配树在链状数据上可能栈溢出，调试时先用 `ulimit -s unlimited`（Linux）或改成显式栈。

不要把有副作用的表达式放进 `assert`，因为 `NDEBUG` 会把它删掉。

## 输入输出与多测

- `ios::sync_with_stdio(false)` 后不要混用 `scanf/printf` 与 `cin/cout`，除非明确处理缓冲顺序。
- 手写快读要处理负号、EOF 和读到非数字；`-0` 应归一化为 0。
- 多测时优先把状态放进 `solve` 的局部对象；必须复用全局数组时使用 `fill`、`clear` 或时间戳。
- 邻接表重置不能只清 `head`：链式前向星的边指针、反图、度数和拓扑队列都要清。
- `freopen`、`assert`、`cerr`、随机种子固定代码都要用条件编译包住；提交前搜索一次这些关键字。

## 整数、除法与位运算

### 1 溢出

- 乘法先提升：`i128(a) * b`；不能等乘完再转换。
- `abs(LLONG_MIN)`、`-numeric_limits<int>::lowest()` 和 `a-b` 都可能溢出；先判断范围。
- 最小化用的 `INF` 不要取最大值，留出至少两次加法余量；最大化同理使用 `-INF`。
- `1LL << k` 只在 `0<=k<63` 时安全；`1 << k` 的类型和位宽取决于字面量，`1<<62` 是典型翻车点。
- 位运算前明确是否需要自然溢出。需要 32 位环时局部使用 `u32`，不要让全局 `#define int long long` 破坏语义。

### 2 向下/向上取整

C++ 的负数 `/` 向零截断。区间分块、类欧和二分答案中若允许负数，使用公共头的 `floor(a,b)`、`ceil(a,b)`，不要直接写 `(a+b-1)/b`。

### 3 模运算

- 取模只适合加、乘、计数；最值比较、排序、概率大小不能先取模。
- 负数归一化写成 `(x%p+p)%p` 或使用 `MInt`；不要假定一次 `x+=p` 就足够，除非已证明 `x>-p`。
- `inv`、除法、阶乘逆元依赖模数为质数或元素互质；合数模要改用扩展欧几里得、CRT 或专用模板。
- 多测动态模数要在构造组合数、NTT 根和逆元表之前调用 `setMod`，不能中途切换。

## STL、PBDS 与哈希

- `vector::erase` 会使后继迭代器失效；循环删除写 `it = v.erase(it)`。
- `priority_queue` 没有遍历接口；需要删除任意元素时改 `multiset`、懒删除堆或可并堆。
- `lower_bound` 的区间必须已按同一比较器排序；`greater<>` 排序后不能用默认比较器查找。
- `map::operator[]` 会插入默认值；只读查询用 `find`，避免无意改变容器和复杂度。
- PBDS 的 `tree` 中 `less_equal` 不是严格弱序，不能直接作为标准 `tree` 比较器；有序多重集用“键值 + 唯一 id”或本库 `03C/03E` 分支。
- `gp_hash_table` 在攻击数据或大量清空时可能退化；预留容量、随机化哈希，或切换到 `cc_hash_table` / `unordered_map`。
- 迭代器、引用和指针在 `vector` 扩容、`unordered_map` rehash、PBDS 修改后都可能失效。

常用的安全删除写法：

```cpp
for (auto it = s.begin(); it != s.end(); ) {
    if (bad(*it)) it = s.erase(it);
    else ++it;
}
```

## 图论与网络流

- Dijkstra 只接受非负边；出现负边时不要“先跑一遍再修正”，改 Bellman-Ford、Johnson 或题目专用方法。
- 无向图的重边不能用 `if (v==fa) continue` 跳过父边，应按边 id 跳过；否则桥、点双和边双会错。
- 缩点后所有边都要重新去重或允许重边，且拓扑 DP 的入度必须基于缩点图，不是原图。
- Floyd 的 `d[i][k]+d[k][j]` 先判断两项可达；负环检测看 `d[i][i]<0`，不要把负边误判成负环。
- 欧拉路要同时检查度数条件和所有非零度点连通；只跑 Hierholzer 会把多个连通块拼成假答案。
- Stoer-Wagner 求无向全局割，不指定源汇；固定源汇、割边恢复和点对最小割要用最大流或 Gomory-Hu。
- 最大流边容量、反向边和总流量可能超过 32 位；反向边必须与正向边成对，当前弧指针每次增广后才能继续。
- 费用流中最短路势能必须在每次残量图改变后保持可行；负费用边不能直接套无势能 Dijkstra。
- 二分图匹配的左右部编号、`pairU/pairV` 初值和 BFS 分层终点必须一致；Kuhn 找增广路前要清 `vis`。
- 支配树只讨论从指定根可达的有向子图；不可达点不是“被 0 支配”，而是没有定义，模板统一返回 0。
- Steiner 树的边权必须非负才能用 Dijkstra 扩展；终端点重复时先去重或按模板约定拒绝。

## 树与数据结构

- LCA 的深度、祖先表和 Euler 序必须统一根；换根后不能继续用旧的 `dep` 解释距离。
- Euler + RMQ 的 O(1) LCA 查询的是 Euler 首次出现区间的最小深度，不是 DFS 序区间的最小编号。
- 树链剖分路径拆分要保证 `top[x]` 深度不大于 `top[y]` 再交换；最后一段是否包含端点取决于题意。
- 点分治/点分树中“删除重心”只影响递归分治结构，不应修改原图；距离桶和子树桶要区分来源，避免同一节点被重复统计。
- 懒标记下推顺序通常是先赋值再加法；合并标记时明确新标记作用在旧值之前还是之后。
- 线段树节点空间通常至少 `4*n`；动态开点需估算“操作次数 × 每次新节点数”，不能只按 `n` 开数组。
- 主席树两棵根相减时，左右子树和计数的符号必须保持一致；第 k 小的 `k` 是 1-indexed 还是 0-indexed 要在接口注释写明。
- DSU on Tree 的 `add/del` 必须互为逆操作；`keep=false` 的轻儿子清理不能漏掉当前重儿子。
- 可撤销并查集禁止路径压缩，只能按秩/大小合并并记录修改栈。

## 数学、多项式与几何

- 组合数先确认 `n<mod`；大 `n` 小质数模使用 Lucas，合数模不能直接套 Lucas。
- 原根、离散对数、NTT 根都依赖模数结构；先分解 `p-1` 或检查单位群阶，不要凭记忆写常数根。
- CRT 合并时先处理非互质模数和负余数；溢出风险用 `i128`，不要把乘法塞回 `int`。
- 多项式长度先补到需要的卷积长度，再做 NTT；逆变换必须乘 `n^{-1}`，且每次蝶形的模减法要归一化。
- 任意模卷积的 CRT 结果需要确认真实答案小于模数乘积；否则增加模数或改用分块/FFT killer 分支。
- 形式幂级数的 `inv/log/exp` 通常要求常数项条件（如 `a[0]!=0`、`a[0]=1`）；截断长度和导数积分的下标要同步。
- 高斯消元选主元时区分“精确为 0”和“绝对值小于 eps”；整数模消元不能使用浮点 eps。
- 几何叉积的符号、共线端点和 `long double` 误差必须统一；排序极角不能直接比较 `atan2` 后忽略边界。
- 凸包是否保留共线点会改变旋转卡壳和点包含答案，模板的 `<=` / `<` 不能随意替换。

## 字符串与 DP

- KMP/Z/Manacher 的下标约定要在空串、长度 1 和偶回文上跑一遍；复制字符串时不要混入哨兵字符。
- 双哈希比较仍可能碰撞；可接受概率风险时随机基，要求确定性时使用后缀数组/自动机或直接比较短串。
- AC 自动机统计出现次数时，fail 树上的计数要在匹配结束后统一汇总；在线输出和离线汇总不能混用。
- SAM 的 `len/link/next` 复制顺序必须先复制转移再改 `len`；不同字符串插入时要重置 `last` 或使用广义版本。
- 区间 DP 先枚举长度再枚举左端点；初始化空区间和不可达状态，否则第一层就会污染答案。
- 01 背包倒序、完全背包正序；“恰好装满”不能把所有状态初始化成 0。
- 单调队列优化前确认队首弹出条件、窗口边界和转移中的减法符号；一个 `<=` 改成 `<` 可能改变方案计数。
- CHT 的斜率方向、查询方向和求最小/最大三件事要同时核对；不满足单调性就换 Li Chao。
- WQS 二分必须记录最优数量并验证随惩罚单调；只二分值而不回收数量会得到相邻数量的错误答案。
- Slope Trick 只维护凸函数；若转移产生非凸拐点，先证明可分解或不要套模板。

## 模拟、牌面与构造

- 牌面比较先做“牌型 + 同级关键字”键，再整体字典序比较；不要只比较最大牌。
- 顺子通常有 A2345 特判；同花顺必须同时满足同花和顺子，四条/葫芦的踢脚牌顺序也要固定。
- 麻将标准型搜索先选将牌，再从最小非零牌尝试刻子和顺子；字牌不能组成顺子，四张相同牌在七对子中的规则要写清。
- 棋盘、坐标、旋转和镜像题先固定一个方向，所有变换都通过同一个函数；不要在输出阶段临时交换行列。
- 构造题先验证总和、奇偶、度数和边界，再输出；“看起来对称”不代表满足最后一列/最后一个元素。
- 日期模拟统一使用半开区间或闭区间，闰年条件写成 `(y%400==0)||(y%4==0&&y%100!=0)`，不要只判断 `%4`。

## 考点

|题面|模板| 前提                                      |
|---|---|---|
|“所有从根到点的路径都必须经过”|支配树|有向图、固定根、只看根可达部分|
|“连接很少的指定点，允许经过中间点”|Steiner 树状态压缩|终端数 `k` 是否足够小、边权是否非负|
|“函数是若干绝对值/折线的和，反复取前缀最小”|Slope Trick|转移后仍是凸分段线性函数|
|“没有指定源汇，问整张无向图最小割”|Stoer-Wagner|不是固定 `s-t` 割，也不要求恢复流量|
|“模数很大/合数，组合数 `n` 远大于模数”|扩展 Lucas / CRT / 质因数分解|模数分解、`n` 与 `k` 的范围|
|“`n` 很大但只出现 `floor(n/i)`、质数前缀和”|整除分块 / 杜教筛 / Min_25|商值段数和所需积性函数|
|“集合大小 `n<=20`，每次合并两个子集”|子集 DP / 子集卷积|`2^n` 内存是否可接受，是否需要 `3^n` 合并|
|“多项式长度不是二的幂或模数不适合 NTT”|任意因子长度 DFT / CRT-NTT / FFT|真实系数上界与模数乘积是否足够|
|“区间加、区间和，操作在线且没有复杂信息”|懒标记线段树或 BIT 差分|是单点/区间更新，还是要维护最值、历史值|
|“答案只依赖最后一次出现位置”|离线 BIT / 扫描线|查询能否按右端点排序，更新是否有后效性|
|“输出任意方案，多个答案都对”|构造 + 校验器思维|输出顺序、重复元素和特殊解是否允许|

## 卡常、缓存与内存池

- 热循环里的数据尽量连续：`vector<vector<E>>` 适合可读性，边数和访问量极大时改用 CSR/链式前向星；预先 `reserve`，避免扩容复制。
- 二重循环优先让内层访问连续内存；矩阵按实际存储顺序遍历。不要为了“看起来对称”交换循环，先看缓存访问模式。
- 大数组放静态区或堆上，别把 `O(n)` 数组放进递归栈；节点数按最坏操作次数估算，不能只按初始 `n` 开池。
- 频繁创建小对象时使用简单内存池；释放时只回退指针，不在热循环里反复 `new/delete`：

```cpp
template <class T, int N> struct Pool {
    array<T, N> a;
    int n = 0;
    T *get() { assert(n < N); return &a[n++]; }
    void clear() { n = 0; }
};
```

- `vector<bool>` 是位代理容器，随机访问和取地址语义都特殊；需要高频修改时优先 `vector<char>` 或 `bitset`。
- `__builtin_ctz*`、`__builtin_clz*`、`popcount*` 的参数类型和零值边界要确认；对 0 调用 `ctz/clz` 是未定义行为。
- 需要 32 位自然溢出时局部使用 `u32`；不要把整个程序改成 32 位而让答案、距离和容量一起溢出。`#define int long long` 造成的内存/缓存损失只有在测出瓶颈后再处理。
- 输出大量方案时先写入 `string` 或缓冲区再一次输出；不要在循环里频繁 `flush`，也不要误用 `endl`（公共宏已将其替换为换行字符串）。
- 浮点累计误差明显时使用 Kahan 补偿；它增加常数，只在误差确实成为瓶颈时使用：

```cpp
ld s = 0, c = 0;
for (ld x : a) {
    ld y = x - c, t = s + y;
    c = (t - s) - y;
    s = t;
}
```

- `-O2`、`-pipe` 通常可用；`-march=native` 可能在评测机不支持，除非平台明确保证，不要把它写进提交依赖。

## 随机化与对拍

最小可用对拍流程：随机生成器、暴力解、正式解、规范化输出、限时循环。生成器要覆盖小范围穷举边界和结构化坏例，而不只是均匀随机。

```cpp
mt19937_64 rng(chrono::steady_clock::now().time_since_epoch().count());
int rd(int l, int r) { return uniform_int_distribution<int>(l, r)(rng); }
```

对拍优先加入：全相等、严格递增/递减、星形/链形/完全图、重复边、孤立点、答案为 0、恰好越界、负数和最大模数。发现差异后固定随机种子，并把最小反例保存成回归测试。

随机哈希不要使用固定易猜的基；哈希值参与下标时先转无符号类型，避免负数取模。模拟退火、随机增量几何和哈希冲突都要在题目允许的错误概率内使用。

```cpp
using i128 = __int128_t;
int mul(int a, int b, int p) { return i128(a) * b % p; }
int norm(int x, int p) { x %= p; if (x < 0) x += p; return x; }
```

### 不溢出的二分中点

```cpp
int m = l + (r - l) / 2;
```

### 坐标压缩后找下标

```cpp
sort(v);
v.erase(unique(v.begin(), v.end()), v.end());
int id = lower_bound(v.begin(), v.end(), x) - v.begin();
```

### 下一段相同值跳转

```cpp
for (int l = 1; l <= n; ) {
    int r = l;
    while (r < n && a[r + 1] == a[l]) ++r;
    // 处理 [l,r]
    l = r + 1;
}
```

### 时间戳清空

```cpp
++tag;
if (vis[x] != tag) vis[x] = tag, val[x] = 0;
```

### 调试断言不改变状态

```cpp
auto ok = check(x);
assert(ok);
```

## 易错点

|表现|最常见原因|修复动作|
|---|---|---|
|小数据正确、大数据 RE|递归栈、节点池或 `4*n` 不够|估算最坏节点数；链图改迭代或加栈|
|随机数据偶发 WA|未定义行为、哈希碰撞、浮点比较|ASan/UBSan，对拍固定种子，几何使用 eps|
|答案差一个模数|负数未归一化或减法只减了一次|统一 `norm` / `MInt`，检查每个分支的范围|
|TLE 但复杂度正确|`#define int long long` 放大了下标数组、缓存未命中|只在确认瓶颈后把下标改 `i32`，并保留注释说明|
|RE 只发生在极端图|孤立点、重边、自环、非连通未处理|先写连通性/度数/边界判定，再调用核心算法|
|本地 AC、评测 CE|依赖 `bits/stdc++.h`、PBDS 或本地头文件|确认题目编译器；提交版走 `ONLINE_JUDGE` 分支|
|调试版结果和提交版不同|`assert` 内含赋值/自增，或调试宏有副作用|把表达式拆成普通语句，再断言纯布尔值|
