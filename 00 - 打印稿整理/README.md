## 重新生成

```powershell
python '.\00 - 打印稿整理\生成打印稿.py'
python '.\00 - 打印稿整理\生成最终PDF.py'
```

生成器会验证顶层编号唯一、目录内索引不重复、每个源码恰好进入一个分册，并检查 Markdown 代码围栏与本地链接。`生成最终PDF.py` 首次运行会按 `package-lock.json` 安装本地渲染依赖。
