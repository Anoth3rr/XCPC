## 仍保留的不同环境分支

- 康托展开：小 `n` 精确反排名 / 大 `n` Fenwick 模排名。
- 最大流：Dinic / HLPP。
- 有序多重集：FHQ Treap / GNU PBDS / 排序 `vector` 小数据版。
- KD Tree：静态最近点/矩形计数 / 动态插入偏序计数。
- 静态 RMQ：ST / Disjoint Sparse Table / 状压线性 RMQ。
- 多重背包：二进制分组 / 单调队列。
- LCS：常规恢复方案 / `uint64_t` 位并行只求长度。
- 高精度整数、定点数、浮点数、进制转换：常规 / 极致卡常。
