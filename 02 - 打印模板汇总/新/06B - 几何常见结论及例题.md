## 第六章补充：几何常见结论及例题

### 常用结论

#### 平面几何结论

- `hypotl(x, y)` 计算 $\sqrt{x^2+y^2}$；最终需要距离时再开方。
- 正 n 边形边长 s、外接圆半径 R，边心距为 $s/(2\tan(\pi/n))=R\cos(\pi/n)$。
- 三角形外接圆半径为 $abc/(4S)=a/(2\sin A)$，内切圆半径为 $2S/(a+b+c)$。
- 边长为单位正三角形 k 倍的大正三角形，由 $k^2$ 个单位正三角形组成。[例题](https://codeforces.com/problemset/problem/559/A)
- 正 n 边形圆心角为 $2\pi/n$；三个不同顶点构成的圆周角为 $k\pi/n$，其中 $1\le k\le n-2$。[例题](https://codeforces.com/problemset/problem/1096/C)
- 点 B 到直线 AC 的距离为 $|(B-A)\times(C-A)|/|C-A|$；一般式 $ax+by+c=0$ 对应 $|ax_B+by_B+c|/\sqrt{a^2+b^2}$。
- `atan2l(y,x)` 可区分四个象限；`atanl(y/x)` 会丢失象限信息，且 x=0 时不能直接相除。
- 依次关于奇数个固定点反射，复合变换为一次中心对称；若按同样顺序循环反射 n 个点，则 $X_{j+2n}=X_j$，最小周期可能更短。[例题](https://codeforces.com/contest/24/problem/C)
- X 关于 A 的对称点为 $2A-X$。
- 海伦公式：令 $p=(a+b+c)/2$，三角形面积为 $\sqrt{p(p-a)(p-b)(p-c)}$；已有坐标时优先使用叉乘。
- 相似平行截面的棱台体积为 $h(S_1+S_2+\sqrt{S_1S_2})/3$。
- 正棱台侧面积为 $(C_1+C_2)L/2$，L 为侧面梯形的高。
- 球表面积为 $4\pi r^2$，体积为 $4\pi r^3/3$。
- 正三角形面积为 $\sqrt3a^2/4$；正四面体表面积为 $\sqrt3a^2$，体积为 $\sqrt2a^3/12$。
- 圆心角为弧度 $\theta$ 的扇形面积为 $\theta R^2/2$。

#### 立体几何结论

- 非零向量 $(x,y,z)$ 的方向余弦为 $x/|v|,y/|v|,z/|v|$，三者平方和为 1。

### 整数例题的公共片段

复用 06A 的 `Point<T>`。以下整数片段约定坐标绝对值不超过 $10^9$，面积统一返回两倍面积；`turn` 使用 `i128` 保留整数判定精度。

```c++
using P = Point<i64>;
i128 turn(P a, P b, P c) {
    return i128(b.x - a.x) * (c.y - a.y) - i128(b.y - a.y) * (c.x - a.x);
}
i128 area2(P a, P b, P c) {
    i128 v = turn(a, b, c);
    return v < 0 ? -v : v;
}
bool onSegment(P a, P b, P p) {
    return turn(a, b, p) == 0 && min(a.x, b.x) <= p.x && p.x <= max(a.x, b.x)
        && min(a.y, b.y) <= p.y && p.y <= max(a.y, b.y);
}
vector<P> convexHullInt(vector<P> a) {
    sort(a.begin(), a.end(), [](P a, P b) { return tie(a.x, a.y) < tie(b.x, b.y); });
    a.erase(unique(a.begin(), a.end(), [](P a, P b) { return a.x == b.x && a.y == b.y; }), a.end());
    int n = a.size();
    if (n <= 1) return a;
    vector<P> h;
    for (auto p : a) {
        while (h.size() >= 2 && turn(h[h.size() - 2], h.back(), p) <= 0) h.pop_back();
        h.push_back(p);
    }
    int k = h.size();
    for (int i = n - 2; i >= 0; --i) {
        while (h.size() > k && turn(h[h.size() - 2], h.back(), a[i]) <= 0) h.pop_back();
        h.push_back(a[i]);
    }
    h.pop_back();
    return h; // 去重、去掉边上中间点，逆时针，不重复首点
}
```

### 常用例题

#### 将平面某点旋转任意角度

返回点 a 绕原点逆时针旋转 d 度后的坐标；绕点 o 旋转时先减 o，最后加回。

```c++
Point<ld> rotateDegrees(Point<ld> a, ld d) {
    ld t = d * acosl(-1.L) / 180;
    return {a.x * cosl(t) - a.y * sinl(t), a.x * sinl(t) + a.y * cosl(t)};
}
```

#### 平面最近点对（set 扫描）

返回距离平方，要求至少两个点，允许重合点。按 x 扫描，仅维护当前距离范围内的点；时间 $O(n\log n)$，空间 $O(n)$。

```c++
i64 closestPair(vector<P> a) {
    assert(a.size() >= 2);
    sort(a.begin(), a.end(), [](P a, P b) { return tie(a.x, a.y) < tie(b.x, b.y); });
    auto dis = [](P a, P b) { return (a.x-b.x)*(a.x-b.x) + (a.y-b.y)*(a.y-b.y); };
    for (int i = 1; i < a.size(); ++i)
        if (a[i].x == a[i-1].x && a[i].y == a[i-1].y) return 0;
    i64 ans = dis(a[0], a[1]);
    set<tuple<i64, i64, int>> st; // y, x, 编号
    for (int i = 0, j = 0; i < a.size(); ++i) {
        while (j < i && (a[i].x-a[j].x)*(a[i].x-a[j].x) > ans) {
            st.erase({a[j].y, a[j].x, j});
            ++j;
        }
        i64 d = sqrtl(ans);
        while (d + 1 <= ans / (d + 1)) ++d;
        while (d && d > ans / d) --d;
        auto it = st.lower_bound({a[i].y-d, numeric_limits<i64>::lowest(), -1});
        for (; it != st.end() && get<0>(*it) <= a[i].y+d; ++it) {
            auto [y, x, id] = *it;
            ans = min(ans, dis(a[i], {x, y}));
        }
        st.insert({a[i].y, a[i].x, i});
    }
    return ans;
}
```

#### 最大四边形面积（简单版，枚举对角线）

要求至少四个点，无重合、无三点共线，允许凹四边形；返回最大两倍面积。枚举对角线，两侧分别取面积最大的三角形，时间 $O(n^3)$。

```c++
i128 maxQuadrilateralBrute(const vector<P> &a) {
    i128 ans = 0;
    for (int i = 0; i < a.size(); i++) {
        for (int j = i + 1; j < a.size(); j++) {
            i128 l = 0, r = 0;
            for (auto p : a) {
                i128 v = turn(a[i], a[j], p);
                if (v > 0) l = max(l, v);
                else r = max(r, -v);
            }
            if (l && r) ans = max(ans, l + r);
        }
    }
    return ans;
}
```

#### 凸包上的最大四边形（旋转卡壳）

输入去掉共线中间点的逆时针凸包，不重复首点；不足四个顶点时返回 0。枚举对角线并维护两侧最远点，时间 $O(h^2)$。

```c++
i128 maxQuadrilateralHull(const vector<P> &p) {
    int n = p.size();
    i128 ans = 0;
    for (int i = 0; i + 3 < n; i++) {
        int k = i + 1, l = i + 3;
        for (int j = i + 2; j + 1 < n; j++) {
            while (k + 1 < j && area2(p[i], p[j], p[k+1]) >= area2(p[i], p[j], p[k])) ++k;
            l = max(l, j + 1);
            while (l + 1 < n && area2(p[i], p[j], p[l+1]) >= area2(p[i], p[j], p[l])) ++l;
            ans = max(ans, area2(p[i], p[j], p[k]) + area2(p[i], p[j], p[l]));
        }
    }
    return ans;
}
```

#### 最大四边形面积（含重合、共线与退化）

从至少四个输入点的不同编号中选择四点，允许退化，返回最大两倍面积；依赖上方 `maxQuadrilateralHull`。凸包至少四点时选凸包顶点；凸包恰有三点时枚举剩余点，用大三角形减最小缺口，时间 $O(n\log n+h^2)$。

```c++
i128 maxQuadrilateral(const vector<P> &a) {
    assert(a.size() >= 4);
    auto h = convexHullInt(a);
    if (h.size() < 3) return 0;
    if (h.size() >= 4) return maxQuadrilateralHull(h);
    array<int, 3> used{};
    i128 ans = 0, s = area2(h[0], h[1], h[2]);
    for (auto p : a) {
        bool skip = false;
        for (int i = 0; i < 3; i++) {
            if (!used[i] && p.x == h[i].x && p.y == h[i].y) {
                used[i] = 1, skip = true;
                break;
            }
        }
        if (skip) continue; // 每个凸包顶点仅消耗一个输入编号，重复点仍可作第四点
        i128 cut = min({area2(p, h[0], h[1]), area2(p, h[1], h[2]), area2(p, h[2], h[0])});
        ans = max(ans, s - cut);
    }
    return ans;
}
```

#### 线段将多边形切割为几个部分

输入简单多边形的边界顺序；线段两端严格在外，线段不经过顶点且不与边重叠。每进出一次增加一块，答案为真交点数除二再加一。

```c++
int cutPieces(const vector<P> &p, P a, P b) {
    auto opposite = [](i128 x, i128 y) { return (x < 0 && y > 0) || (x > 0 && y < 0); };
    int cnt = 0, n = p.size();
    for (int i = 0; i < n; i++) {
        P u = p[i], v = p[(i+1) % n];
        cnt += opposite(turn(a,b,u), turn(a,b,v)) && opposite(turn(u,v,a), turn(u,v,b));
    }
    return cnt / 2 + 1;
}
```

#### 按边界顺序给出的简单多边形是否为凸多边形

检查连续转向是否一致，可接受顺／逆时针；`strict=true` 时不允许相邻三点共线。前提是输入已经是无重复顶点的简单多边形，这个检查不能用于排除星形自交，也不能判断任意无序点集。[例题](https://atcoder.jp/contests/abc266/tasks/abc266_c)

```c++
bool isConvexPolygon(const vector<P> &p, bool strict = true) {
    int n = p.size(), dir = 0;
    if (n < 3) return false;
    for (int i = 0; i < n; i++) {
        i128 v = turn(p[i], p[(i+1)%n], p[(i+2)%n]);
        if (!v) { if (strict) return false; else continue; }
        int s = v > 0 ? 1 : -1;
        if (dir && s != dir) return false;
        dir = s;
    }
    return dir != 0;
}
```

#### 凸包上的最大三角形（枚举首点 + 旋转卡壳）

输入严格逆时针凸包，返回三个顶点下标，不足三点时返回三个 -1；时间 $O(h^2)$。全局最大三角形的反互补三角形包含整个凸包；不能用只移动当前三个顶点的局部爬山代替全局求解。

若最大三角形的顶点为 A、B、C，反互补三角形的顶点为 $B+C-A$、$C+A-B$、$A+B-C$；原三角形是它的中点三角形。

```c++
array<int, 3> maxTriangle(const vector<P> &p) {
    int n = p.size();
    if (n < 3) return {-1, -1, -1};
    array<int, 3> ans{0, 1, 2};
    i128 best = area2(p[0], p[1], p[2]);
    for (int i = 0; i + 2 < n; i++) {
        int k = i + 2;
        for (int j = i + 1; j + 1 < n; j++) {
            k = max(k, j + 1);
            while (k + 1 < n && area2(p[i], p[j], p[k+1]) >= area2(p[i], p[j], p[k])) ++k;
            i128 s = area2(p[i], p[j], p[k]);
            if (s > best) best = s, ans = {i, j, k};
        }
    }
    return ans;
}
```

#### 判断一个凸包是否完全在另一个凸包内

外层 A 为严格逆时针凸包，不重复首点；`inConvex` 返回 0（外部）、1（边界）、2（内部）。对 B 的每个顶点二分判断即可，允许 B 退化，复杂度 $O(|B|\log |A|)$；严格包含时不允许接触 A 的边界。[例题](https://codeforces.com/contest/166/problem/B)

```c++
int inConvex(const vector<P> &a, P p) {
    int n = a.size();
    if (!n) return 0;
    if (n == 1) return p.x == a[0].x && p.y == a[0].y ? 1 : 0;
    if (n == 2) return onSegment(a[0], a[1], p) ? 1 : 0;
    i128 x = turn(a[0], a[1], p), y = turn(a[0], a[n-1], p);
    if (x < 0 || y > 0) return 0;
    if (!x) return onSegment(a[0], a[1], p) ? 1 : 0;
    if (!y) return onSegment(a[0], a[n-1], p) ? 1 : 0;
    int l = 1, r = n - 1;
    while (l + 1 < r) {
        int m = (l + r) / 2;
        if (turn(a[0], a[m], p) >= 0) l = m;
        else r = m;
    }
    i128 v = turn(a[l], a[r], p);
    return v < 0 ? 0 : v == 0 ? 1 : 2;
}
bool containsHull(const vector<P> &a, const vector<P> &b, bool strict = true) {
    for (auto p : b) if (inConvex(a, p) < (strict ? 2 : 1)) return false;
    return true;
}
```
