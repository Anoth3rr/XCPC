## 第十一章：博弈论

### 巴什博弈
有 $N$ 颗石子，两名玩家轮流操作。每次可以取走 $1$ 至 $M$ 颗石子，无法进行合法操作的一方失败。
定义：
$$
r=N\bmod(M+1).
$$

则：
$$
\text{先手必败}\iff r=0
$$
也就是：
- $N\bmod(M+1)=0$ 时，后手必胜；
- $N\bmod(M+1)\ne0$ 时，先手必胜。

当 $r\ne0$ 时，先手先取走 $r$ 颗，使剩余石子数变为 $M+1$ 的倍数。之后若对手取走 $x$ 颗，便取走 $M+1-x$ 颗，从而保证每轮双方总共取走 $M+1$ 颗。

### 扩展巴什博弈
有 $N$ 颗石子，两名玩家轮流操作。每次可以取走 $x$ 颗石子，其中：
$$
a\le x\le b,\qquad 1\le a\le b.
$$

当剩余石子数小于 $a$ 时，无法进行合法操作；无法行动的一方失败。
定义：
$$
r=N\bmod(a+b).
$$

则：
$$
\text{先手必败}\iff r<a
$$

因此：
- $0\le r<a$ 时，后手必胜；
- $a\le r\le b$ 时，先手可以取走 $r$ 颗；
- $b<r<a+b$ 时，先手可以取走 $b$ 颗，使剩余 $r-b<a$，后手无法行动。

普通巴什博弈是 $a=1,\ b=M$ 时的特殊情况。

### Nim 博弈

> 有 $N$ 堆石子，给出每一堆的石子数量，两名玩家轮流行动，按以下规则取石子：
> 
> 规定：每人每次任选一堆，取走正整数颗石子，拿到最后一颗石子的一方获胜（注：其特点是**不能跨堆**、**不能不拿**）。
> 
> 双方均采用最优策略，询问谁会获胜。

记初始时各堆石子的数量 $(A_1,A_2,\dots,A_n)$ ，定义尼姆和 $Sum_N = A_1 \oplus A_2 \oplus \dots \oplus A_n$ 。

**当** $\pmb{ Sum_N = 0 }$ **时先手必败，反之先手必胜。**

### Nim 游戏具体取法

先计算出尼姆和，再对每一堆石子计算 $A_i \oplus Sum_N$ ，记为 $X_i$ 。

若得到的值 $X_i<A_i$ ，$X_i$ 即为一个可行解，即**剩下** $\pmb X_i$ **颗石子，取走** $\pmb {A_i - X_i}$ **颗石子**（这里取小于号是因为至少要取走 $1$ 颗石子）。

### Moore’s Nim 游戏（Nim-K 游戏）

> 有 $N$ 堆石子，给出每一堆的石子数量，两名玩家轮流行动，按以下规则取石子：
> 
> 规定：每人每次至少选择一堆、至多选择 $K$ 堆非空石子堆，并从每个选中的堆中取走正整数颗石子。
> 
> 双方均采用最优策略，询问谁会获胜。

把每一堆石子的石子数用二进制表示，定义 $One_i$ 为二进制第 $i$ 位上 $1$ 的个数。

$$
\text{先手必败}\iff
\forall j,\ One_j\equiv0\pmod{K+1}.
$$

### Anti-Nim 游戏（反 Nim 游戏）

> 有 $N$ 堆石子，给出每一堆的石子数量，两名玩家轮流行动，按以下规则取石子：
> 
> 规定：每人每次任选一堆，取走正整数颗石子，拿到最后一颗石子的一方**出局**。
> 
> 双方均采用最优策略，询问谁会获胜。

以下两种情况先手必胜；除此之外先手必败。

- 所有堆的石子数量均不超过 $1$ ，且 $\pmb {Sum_N=0}$ （也可看作“且有偶数堆”）；
- 至少有一堆的石子数量大于 $1$ ，且 $\pmb{Sum_N \neq 0}$ 。

### 阶梯 - Nim 博弈

> 有 $N$ 级台阶，每一级台阶上均有一定数量的石子，给出每一级石子的数量，两名玩家轮流行动，按以下规则进行操作：
> 
> 规定：每人每次任选一级台阶，拿走正整数颗石子放到下一级台阶中，已经拿到地面上的石子不能再拿，拿到最后一颗石子的一方获胜。
> 
> 双方均采用最优策略，询问谁会获胜。

**对奇数台阶做传统** $\pmb{\tt{}Nim}$ **博弈，当 **$\pmb{Sum_N=A_1\oplus A_3\oplus A_5\oplus\cdots=0}$** 时先手必败，反之先手必胜。**

### 威佐夫博弈

> 有两堆石子，给出每一堆的石子数量，两名玩家轮流行动，每人每次任选以下规定的一种进行操作：
> 
> - 任选一堆，取走正整数颗石子；
> - 从两堆中同时取走相同数量的正整数颗石子。
> 
> 拿到最后一颗石子的一方获胜。双方均采用最优策略，询问谁会获胜。

**以下局面先手必败：**

$\pmb{(1, 2), (3, 5), (4, 7), (6, 10), …}$ 具体而言，每一对的第一个数为此前没出现过的最小整数，第二个数为第一个数加上 $\pmb{1,2,3,4,…}$ 。

更一般地，对于第 $\pmb k$ 对数，第一个数为 $\pmb {First_k= \left \lfloor \frac{k*(1+\sqrt 5)}{2} \right \rfloor}$ ，第二个数为 $\pmb{Second_k=First_k+k}$ 。

其中，在两堆石子的数量均大于 $10^9$ 颗时，由于需要使用高精度计算，我们需要人为定义 $\frac{1+\sqrt 5}{2}$ 的取值为 $lorry = 1.618033988749894848204586834$ 。

```c++
const double lorry = (sqrt(5.0) + 1.0) / 2.0;
//const double lorry = 1.618033988749894848204586834;
void Solve() {
    int n, m; cin >> n >> m;
    if (n < m) swap(n, m);
    double x = n - m;
    if ((int)(lorry * x) == m) cout << "lose\n";
    else cout << "win\n";
}
```

### 斐波那契博弈

> 有一堆石子，数量为 $N$ ，两名玩家轮流行动，按以下规则取石子：
> 
> 先手第1次可以取任意多颗，但不能全部取完，此后每人取的石子数不能超过上个人的两倍，拿到最后一颗石子的一方获胜。
> 
> 双方均采用最优策略，询问谁会获胜。

当且仅当 $N$ 为斐波那契数时先手必败。

```c++
int fib[100] = {1, 2};
map<int, bool> mp;
void init() {
  for (int i = 2; i <= 86; ++ i) fib[i] = fib[i - 1] + fib[i - 2];
    for (int i = 0; i <= 86; ++ i) mp[fib[i]] = 1;
}
void solve() {
    int n; cin >> n;
    if (mp[n] == 1) cout << "lose" << endl;
    else cout << "win" << endl;
}
```

### SG 游戏（有向图游戏）

以下讨论默认游戏满足：双方可执行的操作完全相同、没有随机性、状态图是有限 $\tt DAG$，且每个状态的后继数量有限，并且无法行动的一方失败。
对于一个状态 $u$，定义其 SG 值为：

$$
SG(u)=\operatorname{mex}\{SG(v)\mid u\to v\}
$$

其中 $u\to v$ 表示可以从 $u$ 一步转移到 $v$，且
$$
\operatorname{mex}(S)=\min\{x\in\mathbb Z_{\ge 0}\mid x\notin S\},
\qquad
\operatorname{mex}(\varnothing)=0.
$$

因此：
- 终态没有后继状态，所以 $SG(u)=0$；
- $SG(u)=0$ 时，当前局面为必败态；
- $SG(u)\ne0$ 时，当前局面为必胜态。

若一个游戏由若干个相互独立的子游戏组成，且每次只能操作其中一个子游戏，则总 SG 值为：

$$
SG_{\mathrm{sum}}
=SG_1\oplus SG_2\oplus\dots\oplus SG_k.
$$

当 $SG_{\mathrm{sum}}=0$ 时先手必败，否则先手必胜。
下面以固定减法集合为例。每次可以从一堆石子中取走 $\rm step$ 集合中的任意一个正整数。设 $V$ 为所有石子堆的最大规模，则预处理复杂度为 $\mathcal O(Vm)$。

```c++
int m, n;
vector<int> step, memo, seen;
int stamp = 0;

int sg(int x) {
    if (memo[x] != -1) return memo[x];
    int tag = ++stamp;
    for (int d : step)
        if (d <= x)
            seen[sg(x - d)] = tag;
    int g = 0;
    while (g < (int)seen.size() && seen[g] == tag)
        ++g;
    return memo[x] = g;
}

void solve() {
    cin >> m;
    step.resize(m);
    for (int &d : step) cin >> d;
    cin >> n;
    vector<int> heap(n);
    int V = 0;
    for (int &x : heap) {
        cin >> x;
        V = std::max(V, x);
    }
    memo.assign(V + 1, -1);
    seen.assign(m + 1, 0);
    stamp = 0;
    int sum = 0;
    for (int x : heap)
        sum ^= sg(x);
    cout << (sum == 0 ? "no\n" : "yes\n");
}
```

### Anti-SG 游戏（反 SG 游戏）

Anti-SG 采用反常规则：拿到最后一步的一方失败，等价于无法进行合法操作的一方获胜。
每次选择一个仍可行动的子游戏进行一次操作，其余规则与普通 SG 游戏相同。
设每个子游戏在普通规则下的 SG 值为 $g_i$，并定义：
$$
Sum_{SG}=g_1\oplus g_2\oplus\dots\oplus g_k.
$$

下面的结论需要满足附加条件：
对于每个非终态 $u$，如果 $SG(u)=0$，则至少存在一个后继状态 $v$，使得 $SG(v)=1$。

在满足该条件时，先手必胜当且仅当：
- 所有子游戏的 $\rm SG$ 值都不超过 $1$，且 $Sum_{SG}=0$；
- 至少有一个子游戏的 $\rm SG$ 值大于 $1$，且 $Sum_{SG}\ne0$。
 
否则先手必败。
因此：
$$
\begin{cases}
\text{所有 }g_i\le1:
& \text{先手必胜}\iff Sum_{SG}=0,\\[4pt]
\text{存在 }g_i>1:
& \text{先手必胜}\iff Sum_{SG}\ne0.
\end{cases}
$$

如果题目不满足上述附加条件，则不能直接根据普通 $\rm SG$ 值套用 $\tt Anti-SG$ 结论，需要结合具体游戏重新分析。

### Lasker’s-Nim 游戏（ Multi-SG 游戏）

> 有 $N$ 堆石子，给出每一堆的石子数量，两名玩家轮流行动，每人每次任选以下规定的一种进行操作：
> 
> - 任选一堆，取走正整数颗石子；
> - 任选数量不小于 $2$ 的一堆，分成两堆非空石子。
> 
> 拿到最后一颗石子的一方获胜。双方均采用最优策略，询问谁会获胜。

**本题使用SG函数求解，SG值定义为：**

$$\pmb{ SG(x) = 
\begin{cases}
0 & \text{ , } x = 0\\
x-1 & \text{ , } x\mod 4= 0\\ 
x & \text{ , } x \mod 4 = 1\\ 
x & \text{ , } x \mod 4 = 2\\ 
x+1 & \text{ , } x \mod 4 = 3
\end{cases}}$$

### Every-SG 游戏

以下讨论默认图为有向无环图，且双方拥有完全相同的操作集合。
有 \(K\) 枚棋子分别位于图上的顶点。每一回合中，所有仍然可以移动的棋子都必须移动一次；如果一枚棋子有多个后继顶点，则由当前玩家为它选择一个后继。已经无法移动的棋子保持不动。
当所有棋子都无法移动时，当前玩家失败。
先按照普通 SG 游戏计算每个顶点的 \(SG\) 值，再定义：
$$
step(u)=
\begin{cases}
0, & u\text{ 为终态},\\[4pt]
1+\displaystyle\min_{u\to v} step(v),
& SG(u)=0,\\[8pt]
1+\displaystyle\max_{\substack{u\to v\\SG(v)=0}} step(v),
& SG(u)\ne0.
\end{cases}
$$

其中：
- 当 $SG(u)=0$ 时，所有后继状态的 $\rm SG$ 值都不为 $0$，当前玩家选择使游戏尽快结束的转移；
- 当 $SG(u)\ne0$ 时，至少存在一个 SG 值为 $0$ 的后继状态，当前玩家选择使游戏尽可能延后的转移。
设初始时第 $i$ 枚棋子位于 $u_i$，则整局游戏的结束回合数由：
$$
step_{\max}=\max_{1\le i\le K} step(u_i)
$$

决定。
因此：
$$
\text{先手必胜}\iff step_{\max}\text{ 为奇数}
$$

否则先手必败。
在 $\tt DAG$ 上，可以按照拓扑序逆序计算 $SG(u)$ 和 $step(u)$。使用时间戳数组实现 $\tt mex$ 时，复杂度通常为 $\mathcal O(|V|+|E|+K)$。

### 树上删边游戏

> 给出一棵 $N$ 个节点的有根树，两名玩家轮流行动，按以下规则操作：
> 
> 选择一条边删除，与根不连通的部分一并删除。删掉最后一条可删边的一方获胜；没有可删边的一方失败。

结论：当根节点SG值非 $0$ 时先手必胜。

**相较于传统SG值的定义，本题的SG函数值定义为：**

- 叶子节点的SG值为 $\pmb 0$ 。
- 非叶子节点的SG值为其所有孩子节点SG值 $\pmb + 1$ 的异或和。

```c++
auto dfs = [&](auto&& self, int u, int fa) -> int {
    int g = 0;
    for (int v : ver[u]) {
        if (v == fa) continue;
        g ^= self(self, v, u) + 1;
    }
    return g;
};

cout << (dfs(dfs, 1, 0) == 0 ? "Bob" : "Alice") << endl;
```

### 无向图删边游戏（Fusion Principle 定理）

> 给出一张 $N$ 个节点的无向连通图，有一个点作为图的根，两名玩家轮流行动，按以下规则操作：
> 
> 选择任意一条边删除，不与根相连的部分会同步被删去；
> 
> 删掉最后一条边的一方获胜。双方均采用最优策略，询问谁会获胜。

将环上的顶点缩成一个点；若环的边数为奇数，则再从该点连接一条新叶边；若为偶数，则不添加叶边。

此时，本模型转化为“树上删边游戏”。
