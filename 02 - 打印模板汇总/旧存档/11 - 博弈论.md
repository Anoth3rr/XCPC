## 博弈论

### 巴什博弈

> 有 $N$ 个石子，两名玩家轮流行动，按以下规则取石子：
>
> 规定：每人每次可以取走 $X(1 \le X \le M)$ 个石子，拿到最后一颗石子的一方获胜。
>
> 双方均采用最优策略，询问谁会获胜。

> 两名玩家轮流报数。
>
> 规定：第一个报数的人可以报 $X(1 \le X \le M)$ ，后报数的人需要比前者所报数大 $Y(1 \le Y \le M)$ ，所报数字不得超过 $N$ ，率先报到 $N$ 的人获胜。
>
> 双方均采用最优策略，询问谁会获胜。

$$
\text{先手必败}\iff N\bmod(M+1)=0.
$$

- 对于 $N = K\cdot (M+1)$ ，后手可以控制双方正好取走 $M+1$ 个。
- 对于剩余情况，先手可以先取走 $R = N \bmod (M+1)$ 个，随后等价于情况一交换先后手。

### 扩展巴什博弈

> 有 $N$ 颗石子，两名玩家轮流行动，按以下规则取石子：
>
> 规定：每人每次可以取走 $X(a \le X \le b)$ 个石子，如果最后剩余物品的数量小于 $a$ 个，则不能再取，无法进行合法操作的一方失败。
>
> 双方均采用最优策略，询问谁会获胜。

$$
\text{先手必败}\iff N\bmod(a+b)<a\quad(1\leq a\leq b)
$$

- $N = K\cdot(a+b)$ 时，后手必胜，同巴什博弈。
- $N = K\cdot(a+b)+R_1\left(1\leq R_1 < a\right)$，这些数量不够再取一次，先手无法逆转局面；
- $N = K\cdot(a+b)+R_2\left(a\leq R_2 \leq b\right)$ ，同巴什博弈；
- $N = K\cdot(a+b)+R_3\left(b< R_2\right)$ ，取走 $b$ 后，余 $R_3-b<a$ ，这些数量不够再取一次，后手无法逆转局面；

### 减法游戏（Subtraction Game）

> 有 $N$ 堆石子，给出每一堆的石子数量。两名玩家轮流行动，按以下规则取石子：
>
> 规定：每次任选一堆，从中取走的石子数量必须属于正整数集合
> $S=\{a_1,a_2,\dots,a_m\}$。
>
> 无法进行合法操作的一方失败。双方均采用最优策略，询问谁会获胜。

定义单堆有 $x$ 颗石子时的 $\texttt{SG}$ 值为 $SG(x)$：

$$
SG(0)=0
$$

$$
SG(x)=\operatorname{mex}\{SG(x-a_i)\mid a_i\le x\}
$$

多个石子堆的总 $\texttt{SG}$ 值为：

$$
Sum_{SG}=SG(A_1)\oplus SG(A_2)\oplus\dots\oplus SG(A_N)
$$

**当** $\pmb{Sum_{SG}=0}$ **时先手必败，反之先手必胜。**

巴什博弈是 $S=\{1,2,\dots,M\}$ 的特例，扩展巴什博弈是 $S=\{a,a+1,\dots,b\}$ 的特例。

当 $S$ 固定且有限时，$SG(x)$ 序列最终具有周期性。

### Nim 博弈

> 有 $N$ 堆石子，给出每一堆的石子数量，两名玩家轮流行动，按以下规则取石子：
>
> 规定：每人每次任选一堆，取走正整数颗石子，拿到最后一颗石子的一方获胜（注：几个特点是**不能跨堆**、**不能不拿**）。
>
> 双方均采用最优策略，询问谁会获胜。

记初始时各堆石子的数量 $(A_1,A_2,\dots,A_n)$ ，定义尼姆和 $Sum_N = A_1 \oplus A_2 \oplus \dots \oplus A_n$ 。

**当** $\pmb{ Sum_N = 0 }$ **时先手必败，反之先手必胜。**

### Nim 游戏具体取法

先计算出尼姆和，再对每一堆石子计算 $A_i \oplus Sum_N$ ，记为 $X_i$ 。

若得到的值 $X_i<A_i$ ，$X_i$ 即为一个可行解，即**剩下** $\pmb X_i$ **颗石头，取走** $\pmb {A_i - X_i}$ **颗石头**（这里取小于号是因为至少要取走 $1$​ 颗石子）。

只有 $Nim$ 和非零时，才保证存在 $X_i<A_i$。

### Moore’s Nim 游戏（Nim-K 游戏）

> 有 $N$ 堆石子，给出每一堆的石子数量，两名玩家轮流行动，按以下规则取石子：
>
> 规定：每人每次任选至少 $1$ 堆，至多 $K$ 堆，对每堆都取走任意多的正整数颗石子，拿到最后一颗石子的一方获胜。
>
> 双方均采用最优策略，询问谁会获胜。

把每一堆石子的石子数用二进制表示，定义 $One_i$ 为二进制第 $i$ 位上 $1$ 的个数。
$$
\text{先手必败}\iff
\forall j\ge0,\ One_j\equiv0\pmod{K+1}
$$

### Anti-Nim 游戏（反 Nim 游戏）

> 有 $N$ 堆石子，给出每一堆的石子数量，两名玩家轮流行动，按以下规则取石子：
>
> 规定：每人每次任选一堆，取走正整数颗石子，拿到最后一颗石子的一方**出局**。
>
> 双方均采用最优策略，询问谁会获胜。

以下局面先手必胜：

- 所有堆的石头数量均不超过 $1$ ，且 $\pmb {Sum_N=0}$ （也可看作“且有偶数个非空堆”）；
- 至少有一堆的石头数量大于 $1$ ，且 $\pmb{Sum_N \neq 0}$ 。

### 阶梯 - Nim 博弈

> 有 $N$ 级台阶，地面编号为 $0$ ，每一级台阶上均有一定数量的石子，给出每一级石子的数量，两名玩家轮流行动，按以下规则操作石子：
>
> 规定：每人每次任选一级台阶，拿走正整数颗石子放到下一级台阶中，已经拿到地面上的石子不能再拿，拿到最后一颗石子的一方获胜。
>
> 双方均采用最优策略，询问谁会获胜。

**对奇数台阶做传统** $\pmb{\tt{}Nim}$ **博弈，当** $\pmb{Sum_N=0}$ **时先手必败，反之先手必胜。**

### SG 游戏（有向图游戏）

我们使用以下几条规则来定义暴力求解的过程：

- 使用数字来表示输赢情况，$0$ 代表局面必败，**非 $0$ 代表当前行动方存在必胜策略**，我们称这个数字为这个局面的SG值；
- 找到最终态，根据题意终态 $\texttt{SG}$ 值为 $0$；
- 对于非最终态的某个节点，其 $\texttt{SG}$ 值为所有子节点的 $\texttt{SG}$ 值取 $\tt{}mex$ ；
- 单个游戏的输赢态即对应根节点的 $\texttt{SG}$ 值是否为 $0$ ，为 $0$ 代表先手必败，非 $0$ 代表先手必胜；
- 多个游戏的总 $\texttt{SG}$ 值为单个游戏 $\texttt{SG}$ 值的异或和，**子游戏相互独立，每次恰好操作其中一个**。

$$
\operatorname{mex}(S)=\min\{t\in\mathbb Z_{\ge0}:t\notin S\},
\qquad\operatorname{mex}(\varnothing)=0.
$$

使用哈希表，以 $\mathcal{O} (状态数 * 可选操作数)$ 的复杂度计算。

```c++
int n, m, a[N], num[N];
int sg(int x) {
    if (num[x] != -1) return num[x];
    
    unordered_set<int> S;
    for (int i = 1; i <= m; ++ i) 
        if(x >= a[i]) 
            S.insert(sg(x - a[i]));
    
    for (int i = 0; ; ++ i)
        if (S.count(i) == 0)
            return num[x] = i;
}
void Solve() {
    cin >> m;
    for (int i = 1; i <= m; ++ i) cin >> a[i];
    cin >> n;
    
    int ans = 0; memset(num, -1, sizeof num);
    for (int i = 1; i <= n; ++ i) {
        int x; cin >> x;
        ans ^= sg(x);
    }
    
    if (ans == 0) no;
    else yes;
}
```

### Anti-SG 游戏（反 SG 游戏）

> 有若干个相互独立的有限无偏游戏。两名玩家轮流行动：
>
> 规定：每次任选一个尚可行动的子游戏进行一次操作。
>
> 无法行动的一方获胜。双方均采用最优策略，询问谁会获胜。

**本结论仅适用于满足以下条件的游戏：**

- 对每个非终态 $u$，若 $SG(u)=0$，则存在一个后继状态 $v$ 满足 $SG(v)=1$。

设所有子游戏普通规则下的 SG 值异或和为 $Sum_{SG}$。

**以下局面先手必胜：**

- 所有单局游戏的 SG 值均不超过 $\pmb 1$，且 $\pmb{Sum_{SG}=0}$；
- 至少有一局单局游戏的 SG 值大于 $\pmb 1$，且 $\pmb{Sum_{SG}\ne0}$。

若题目未保证上述条件，则不能直接套用 Anti-SG 结论。

### Lasker’s-Nim 游戏（ Multi-SG 游戏）

> 有 $N$ 堆石子，给出每一堆的石子数量，两名玩家轮流行动，每人每次任选以下规定的一种操作石子：
>
> - 任选一堆，取走正整数颗石子；
> - 任选数量不小于 $2$ 的一堆，分成两堆非空石子。
>
> 拿到最后一颗石子的一方获胜。双方均采用最优策略，询问谁会获胜。

**本题使用SG函数求解，SG值定义为：**

$$
SG(0)=0,\;\pmb{ SG(x) = 
\begin{cases}
x-1 & \text{ , } x\mod 4= 0\\ 
x & \text{ , } x \mod 4 = 1\\ 
x & \text{ , } x \mod 4 = 2\\ 
x+1 & \text{ , } x \mod 4 = 3
\end{cases}}
$$

### Every-SG 游戏

> 给出一个有向无环图，其中 $K$ 个顶点上放置了石子，两名玩家轮流行动，按以下规则操作石子：
>
> 移动图上所有还能够移动的石子；
>
> 无法移动石子的一方出局。双方均采用最优策略，询问谁会获胜。

设 $SG(u)$ 是单个棋子按普通规则计算的 $\texttt{SG}$ 值，正确递推为：

$$
step(u)=
\begin{cases} 0,&u\text{ 为终态},\\
1+\displaystyle\max_{\substack{u\to v\\SG(v)=0}}step(v), &SG(u)\ne0,\\
1+\displaystyle\min_{u\to v}step(v), &SG(u)=0,\ u\text{ 非终态}. \end{cases}
$$

若初始棋子位于 $u_1,\dots,u_K$，则：

$$
\text{先手必胜}\iff \max_i step(u_i)\text{ 为奇数}
$$

### 威佐夫博弈

> 有两堆石子，给出每一堆的石子数量，两名玩家轮流行动，每人每次任选以下规定的一种操作石子：
>
> - 任选一堆，取走正整数颗石子；
> - 从两堆中同时取走相同正整数颗石子。
>
> 拿到最后一颗石子的一方获胜。双方均采用最优策略，询问谁会获胜。

**以下局面先手必败：**

$\pmb{ (1, 2), (3, 5), (4, 7), (6, 10), …}$ 具体而言，每一对的第一个数为此前没出现过的最小整数，第二个数为第一个数加上 $\pmb{1,2,3,4,…}$ 。

更一般地，对于第 $\pmb k$ 对数，第一个数为 $\pmb {First_k= \left \lfloor \frac{k*(1+\sqrt 5)}{2} \right \rfloor}$ ，第二个数为 $\pmb{Second_k=First_k+k}$​ 。

即设 $a\le b$、$k=b-a$，则 $(a,b)$ 为必败态当且仅当 $a=\lfloor k\varphi\rfloor$。

其中，在两堆石子的数量均大于 $10^9$ 次时，由于需要使用高精度计算，我们需要人为定义 $\frac{1+\sqrt 5}{2}$ 的取值为 $lorry = 1.618033988749894848204586834$​ 。

```c++
void solve() {
    int a, b;
    cin >> a >> b;
    if (a > b) swap(a, b);
    int k = b - a;
    if (k * mysqrt(5 * k * k) / 2 == a) cout << "lose" << endl;
    else cout << "win" << endl;
}
```

### 斐波那契博弈

> 有一堆石子，数量为 $N$ ，两名玩家轮流行动，按以下规则取石子：
>
> 先手第1次可以取任意多颗，但不能全部取完，此后每人取的石子数不能超过上个人的两倍，拿到最后一颗石子的一方获胜。
>
> 双方均采用最优策略，询问谁会获胜。

当且仅当 $N$ 为斐波那契数时先手必败。

```c++
map<int, bool> mp;
void init() {
    auto f = fib(N);
    for (auto v : f) mp[v] = 1;
}
void Solve() {
    int n;
    cin >> n;
    if (mp[n] == 1) cout << "lose" << endl;
    else cout << "win" << endl;
}
```

### 树上删边游戏

> 给出一棵 $N$ 个节点的有根树，两名玩家轮流行动，按以下规则操作：
>
> 选择任意一棵子树并删除（即删去任意一条边，不与根相连的部分会同步被删去）；
>
> 删掉最后一棵子树的一方获胜（换句话说，删去根节点的一方失败）。双方均采用最优策略，询问谁会获胜。

**相较于传统 $\texttt{SG}$ 值的定义，本题的 $\texttt{SG}$ 函数值定义为：**

- 叶子节点的 $\texttt{SG}$ 值为 $\pmb 0$ 。
- 非叶子节点的 $\texttt{SG}$ 值 $SG(u)=\bigoplus\limits_{v\text{ 为 }u\text{ 的孩子}}(SG(v)+1)$。

$$
\text{先手必胜}\iff SG(root)\ne0
$$

```c++
auto dfs = [&](auto self, int u, int fa) -> int {
    int res = 0;
    for (int v : ver[u]) {
        if (v == fa) continue;
        res ^= (self(self, v, u) + 1);
    }
    return res;
};
cout << (dfs(dfs, 1, 0) == 0 ? "Bob" : "Alice") << endl;
```

### 无向图删边游戏（Fusion Principle 定理）

> 给出一张 $N$ 个节点的无向连通图，有一个点作为图的根，两名玩家轮流行动，按以下规则操作：
>
> 选择任意一条边删除，不与根相连的部分会同步被删去；
>
> 删掉最后一条边的一方获胜。双方均采用最优策略，询问谁会获胜。

- **对于奇环，我们将其缩点后外挂一条连接新叶子节点的边；**
- **对于偶环，我们将其缩成一个新点；**
- **所有连接到原来环上的边全部与新点相连。**

此时，本模型转化为“树上删边游戏”。

### Nimble 游戏

> 有若干枚棋子位于编号为 $0,1,\dots,N$ 的格点上。
> 两名玩家轮流行动，每次任选一枚棋子，将其向左移动任意正数格。
>
> 允许多个棋子位于同一个格点。位于 $0$ 号格点的棋子无法移动。
>
> 无法移动棋子的一方失败。双方均采用最优策略，询问谁会获胜。

记 $cnt_i$ 为第 $i$ 个格点上的棋子数量，定义尼姆和：

$$
Sum_N=\bigoplus_{cnt_i\bmod 2=1} i
$$

即只对棋子数量为奇数的格点编号进行异或。

**当** $\pmb{Sum_N=0}$ **时先手必败，反之先手必胜。**

### Grundy's Game（拆分博弈）

> 有 $N$ 堆石子，给出每一堆的石子数量。两名玩家轮流行动：
>
> 规定：每次任选一堆石子，将其分成两堆数量不同的非空石子。
>
> 无法操作的一方失败。双方均采用最优策略，询问谁会获胜。

设一堆大小为 $x$ 的石子的 SG 值为 $SG(x)$：

$$
SG(0)=SG(1)=SG(2)=0\\
SG(x)=\operatorname{mex}
\{SG(i)\oplus SG(x-i)\mid 1\le i<x-i\}
$$

其中 $i<x-i$ 保证分出的两堆石子数量不同。

多个石子堆的总 SG 值为：

$$
Sum_{SG}=SG(A_1)\oplus SG(A_2)\oplus\dots\oplus SG(A_N)
$$

**当** $\pmb{Sum_{SG}=0}$ **时先手必败，反之先手必胜。**

### Dawson's Kayles 游戏

> 有 $N$ 个连续排列的棋子。两名玩家轮流行动：
>
> 规定：每次任选两个相邻棋子并将其删除。删除后，左右两侧剩余的连续棋子视为两个独立游戏。
>
> 无法删除相邻棋子的一方失败。双方均采用最优策略，询问谁会获胜。

设一段连续 $x$ 个棋子的 SG 值为 $SG(x)$：

$$
SG(0)=SG(1)=0
$$

$$
SG(x)=\operatorname{mex}
\{SG(i)\oplus SG(x-i-2)\mid 0\le i\le x-2\}
$$

若初始局面包含多段互不相连的连续棋子，则总 SG 值为各段 SG 值的异或和。

**当总 SG 值为** $\pmb 0$ **时先手必败，反之先手必胜。**
