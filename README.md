## 公共约定

开局模板只保留完整版与极简版：完整版内联常用宏与函数，并在本地包含 `linyue.hpp`；极简版直接包含 `bits/stdc++.h`。除文件首部另有说明外，两者均使用 `std` 命名空间并遵循：

```cpp
#define int long long
#define pii array<int, 2>
#define endl "\n"
```

- 同一问题的不同数据范围或编译环境实现使用同号分支，如 Dinic / HLPP 为 `01A / 01B`。
- 若后者直接以前者为前置，继续追加分支字母；不同问题使用不同根编号。
- 模意义计数和域运算优先接收 `MInt` 等自动取模类型；运行时合数模、64 位模乘等保留显式模数接口。
- 命名统一遵循：模板/类型不超过 10 字符，函数不超过 7 字符，变量、字段、参数和模板参数不超过 3 字符；查询用 `ask`，定向查询用 `askMax / askMin / askGCD`，区间更新用 `update`，单点更新用 `modify`。
- 默认所有普通整数、下标、状态、权值和答案都使用宏展开后的 `int`；仅在实际超时、超空间或需要自然溢出、确定位宽时使用其他整型。
- 开局头文件不预置短类型别名。模板按需局部声明 `ld / i32 / i64 / u32 / u64 / i128 / u128`，且固定宽度长类型名只出现在对应别名声明右侧。
- 不对 `.size()` 结果强转为 `int`，除非省略后会直接编译失败；`size_t` 只保留在哈希返回值等标准库接口签名中。可能因 64 位下标放大内存的模板只在注释中提示卡常改法，默认代码仍以简洁统一为先。
- 相似模板只有在功能、前提、复杂度和环境均相同时才合并；环境特化与卡常分支全部保留。

## 打印稿

`00 - 打印稿整理` 中有每个版块 1–2 份 Markdown 分册，以及唯一的 [XCPC 全量打印稿](00%20-%20打印稿整理/00%20-%20XCPC全量打印稿.md)。全量稿已内嵌封面、两级目录、分册扉页、A4 分页、页眉页脚与页码样式。生成前会先运行 [覆盖矩阵](00%20-%20打印稿整理/模板覆盖矩阵.md)，检查新增模板是否已完成问题族审查；随后检查编号、漏收、重复收录、代码围栏与本地链接：

```powershell
python '.\00 - 打印稿整理\coverage_audit.py'
python '.\00 - 打印稿整理\生成打印稿.py'
python '.\00 - 打印稿整理\生成最终PDF.py'
```

第二条命令会两遍排版、回填与页脚一致的物理页码，并生成带 PDF 书签和“林月”作者元数据的最终文件。打印稿是源码的机械快照；修改模板后应重新生成，不直接手改分册正文。
